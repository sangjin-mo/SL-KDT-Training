## 먼저 따라 하는 핵심 수업

### 수업 1. 변수는 값에 붙인 이름이다

문자열, 정수, 실수, 논리값을 각각 변수에 연결한다. `type()`은 값이 어떤 자료형의 객체인지 알려준다.

**소스코드**

```python
name = "홍길동"
age = 21
score = 95.5
is_student = True

print(f"이름: {name}, 자료형: {type(name)}")
print(f"나이: {age}, 자료형: {type(age)}")
print(f"점수: {score}, 자료형: {type(score)}")
print(f"학생 여부: {is_student}, 자료형: {type(is_student)}")
```

**실행 결과**

```text
이름: 홍길동, 자료형: <class 'str'>
나이: 21, 자료형: <class 'int'>
점수: 95.5, 자료형: <class 'float'>
학생 여부: True, 자료형: <class 'bool'>
```

`name`은 변수명, `"홍길동"`은 문자열 값이다. `True`와 `"True"`는 자료형이 다르다. 변수에 다시 대입하면 해당 이름이 가리키는 객체가 바뀐다.

### 수업 2. 입력받은 숫자는 아직 문자열이다

DAY02의 입력 실습과 DAY03의 형 변환을 함께 이해한다. 키보드에서 7을 입력해도 input의 반환값은 문자열 `"7"`이다.

**소스코드**

```python
first = input("첫 번째 숫자: ")
second = input("두 번째 숫자: ")

print(f"문자열 연결: {first + second}")
print(f"정수 덧셈: {int(first) + int(second)}")

num = 4
float(num)             # 반환된 4.0을 저장하지 않음
print(type(num))
num = float(num)       # 반환된 4.0에 num을 다시 연결
print(type(num))
```

**7과 3을 입력했을 때 실행 결과**

```text
첫 번째 숫자: 7
두 번째 숫자: 3
문자열 연결: 73
정수 덧셈: 10
<class 'int'>
<class 'float'>
```

`float(num)`만 호출해도 num 자체가 바뀌지는 않는다. 결과를 기존 이름에 재할당하거나 다른 변수에 저장할 수 있다. 숫자가 아닌 입력을 int로 바꾸면 ValueError가 발생한다.

### 수업 3. print의 구분자와 종료 문자를 구분한다

**소스코드**

```python
print("A", "B")                  # 기본 구분자는 공백
print("A", "B", sep="*")         # 값 사이에 별 삽입
print("A", "B", sep="", end="★") # 줄 바꿈 대신 별로 종료
print("다음 출력")
```

**실행 결과**

```text
A B
A*B
AB★다음 출력
```

`sep`는 여러 값 사이, `end`는 마지막에 붙는다. 문자열 내부에 직접 적은 공백은 sep로 제거되지 않는다. f-string의 `{변수}`는 해당 위치에 값을 넣는다.

### 수업 4. 파일에 자기소개 문장을 저장한다

DAY02 실습의 핵심 흐름은 입력 → 변수 → 문장 조합 → 파일 저장이다. 다음은 입력 부분 없이도 바로 실행해 볼 수 있는 해설용 예제다.

**소스코드**

```python
name = "홍길동"
major = "전자공학"
graduation = "졸업한"
like = "코딩"
dislike = "지각"
want = "개발자로 일"

myfile = open("intro.txt", mode="w", encoding="utf-8")
myfile.write(f"저의 이름은 {name}입니다.\n")
myfile.write(f"저는 {major}을 전공했습니다.\n")
myfile.write(f"저는 현재 {graduation} 상태입니다.\n")
myfile.write(f"좋아하는 것은 {like}이고 싫어하는 것은 {dislike}입니다.\n")
myfile.write(f"저는 {want}하고 싶습니다.\n")
myfile.close()
```

**intro.txt에 저장되는 내용**

```text
저의 이름은 홍길동입니다.
저는 전자공학을 전공했습니다.
저는 현재 졸업한 상태입니다.
좋아하는 것은 코딩이고 싫어하는 것은 지각입니다.
저는 개발자로 일하고 싶습니다.
```

터미널에 출력하는 코드가 아니라 파일에 쓰는 코드다. 상대경로 `intro.txt`의 저장 위치는 현재 작업 폴더이며, w 모드는 기존 내용을 덮어쓴다. write는 줄 바꿈을 자동으로 넣지 않아 `\n`을 직접 붙였다.

### 수업 5. 문자열에서 필요한 부분만 가져온다

공백도 문자다. 끝에 공백이 있는 다음 문자열의 길이는 38이다. len에서 센 개수와 마지막 인덱스는 1만큼 차이가 난다.

**소스코드**

```python
msg = "Merry Christmas! Happy New Year 2027! "

print(f"길이: {len(msg)}")
print(f"첫 문자: {msg[0]}")
print(f"마지막 문자: {repr(msg[-1])}")
print(f"인덱스 6~14: {msg[6:15]}")
print(f"인덱스 32~36: {msg[32:37]}")
print(f"마지막 공백 포함: {repr(msg[32:])}")
```

**실행 결과**

```text
길이: 38
첫 문자: M
마지막 문자: ' '
인덱스 6~14: Christmas
인덱스 32~36: 2027!
마지막 공백 포함: '2027! '
```

`[6:15]`는 6 이상·15 미만을 선택한다. 음수 인덱스 -1은 마지막 문자이며 이 예제에서는 공백이다. repr은 보이지 않는 끝 공백을 따옴표 안에서 확인할 수 있도록 사용했다.

### 수업 6. 간격을 지정하면 규칙적으로 고를 수 있다

**소스코드**

```python
sample = "abcdef"
print(sample[::2])
print(sample[1::2])
print(sample[::-1])

data = "abc1abc2abc3abc4abc5"
print(data[3::4])

print(f"'123'의 원소 개수 => {len('123')}개")
```

**실행 결과**

```text
ace
bdf
fedcba
12345
'123'의 원소 개수 => 3개
```

| 표현 | 읽는 방법 |
|---|---|
| `[::2]` | 0부터 2칸씩, 짝수 인덱스 선택 |
| `[1::2]` | 1부터 2칸씩, 홀수 인덱스 선택 |
| `[::-1]` | 마지막부터 역순으로 선택 |
| `[3::4]` | 3부터 4칸씩 선택 |

`[3::4]`는 숫자를 판별하는 코드가 아니라 위치 규칙을 이용한 선택이다. 마지막 print는 PY311에서도 실행되도록 바깥 큰따옴표와 안쪽 작은따옴표를 구분했다. len('123')은 가능하지만 len(123)은 TypeError다.

- **base의 패키지는 PY311에 자동으로 복사되지 않는다.**

## 4. DAY02 핵심 개념

### 4.1 객체 참조와 변수 재할당

```python
value = 3
age = 3

print(id(value))
print(id(age))

age = 100
```

`age = 100`은 기존 정수 객체 `3`을 바꾸는 것이 아니라, `age`가 다른 객체를 가리키도록 다시 연결하는 것이다. `value`는 여전히 `3`을 가리킨다.

`id()`는 객체가 살아 있는 동안 고유하고 일정한 **객체 식별값**을 반환한다. CPython에서는 메모리 주소에 해당하지만, 모든 Python 구현에서 주소라고 보장되는 것은 아니다.

작은 정수 등 일부 객체는 재사용되어 같은 `id()`가 관찰될 수 있다. 그러나 **값이 같은 모든 데이터가 언제나 하나의 객체로 저장되는 것은 아니다.** 값 비교에는 `==`, 같은 객체인지 확인할 때는 `is`를 사용한다.

### 4.2 print(): sep와 end

```python
print("홍길동", 2027)
# 홍길동 2027 + 줄 바꿈

print("홍길동", 2027, sep="*")
# 홍길동*2027 + 줄 바꿈

print("홍길동", 2027, sep="", end="★")
# 홍길동2027★ — 자동 줄 바꿈 없음
```

| 옵션 | 역할 | 기본값 |
|---|---|---|
| `sep` | 여러 출력 값 사이 구분자 | `" "` |
| `end` | 출력 마지막에 붙는 문자열 | `"\n"` |
| `file` | 출력할 대상 | 표준 출력, 일반적으로 터미널 |

`sep=""`로 지정해도 문자열 안에 직접 입력한 공백은 유지된다. `end`를 별 등으로 바꾸면 다음 `print()` 출력이 같은 줄에 이어질 수 있다.

### 4.3 문자열 출력 형식 비교

```python
year, month, day = 2026, 11, 18

print("오늘은 ", year, "년 ", month, "월 ", day, "일입니다", sep="")
print("오늘은 %d년 %d월 %d일입니다" % (year, month, day))
print(f"오늘은 {year}년 {month}월 {day}일입니다")
```

| 방식 | 특징 |
|---|---|
| 쉼표로 값 나열 | 여러 값을 전달하며 `sep`로 구분 방식 조절 |
| `%` 서식 | 자리와 변수의 개수·순서, 서식 종류를 맞춤 |
| f-string | 문자열 앞에 `f`, 삽입할 변수·표현식을 `{}`로 표시 |

| 서식 | 의미 | 예시 |
|---|---|---|
| `%d` | 정수 형식 | `2026` |
| `%f` | 실수 형식, 기본 소수점 이하 6자리 | `2026.000000` |
| `%s` | 문자열 표현 | `2026` |

**실습의 `%f` 출력은 `%d`, `%s` 출력과 다르다.** 정수를 넣어도 소수점 이하가 표시된다. 일반적인 문장 조합에는 f-string을 기본으로 활용한다.

```python
score = 95.567
print(f"점수: {score:.2f}")  # 점수: 95.57
```

### 4.4 input(): 입력과 형 변환

```python
first = input("숫자 1 입력: ")
second = input("숫자 2 입력: ")

print(first + second)
print(int(first) + int(second))
```

`7`, `3`을 입력하면 첫 출력은 문자열 연결 결과 `73`, 두 번째는 숫자 덧셈 결과 `10`이다.

- `input()`은 Enter를 누를 때까지 기다리며, 입력 결과를 문자열로 반환한다.
- 정수 계산에는 `int()`, 실수 계산에는 `float()` 등을 사용한다.
- `int("안녕")`처럼 변환할 수 없는 문자열을 넣으면 `ValueError`가 발생한다.

### 4.5 파일 처리: 열기 → 작업 → 닫기

```python
FILE_NAME = "test.txt"

myfile = open(FILE_NAME, mode="w", encoding="utf-8")
myfile.write("good luck!\n")
myfile.write("Happy Python!")
myfile.close()
```

| 항목 | 의미 |
|---|---|
| `open()` | 파일을 열고 파일 객체 반환 |
| `mode="r"` | 읽기, 기본 모드 |
| `mode="w"` | 쓰기, 기존 파일이 있으면 내용 삭제 후 기록 |
| `mode="a"` | 기존 내용 뒤에 추가 |
| `encoding="utf-8"` | 텍스트를 저장·해석할 문자 인코딩 지정 |
| `write(문자열)` | 문자열 기록, 줄 바꿈은 자동 추가하지 않음 |
| `close()` | 버퍼 내용을 반영하고 파일 자원 해제 |

`r`, `w`, `a`는 이 예제에서 **파일 열기 모드**이며 `myfile.w()` 같은 메서드가 아니다. 대문자 `FILE_NAME`은 상수처럼 사용한다는 명명 관례이며, Python이 값 변경을 금지하지는 않는다.

`print()`로도 파일에 기록할 수 있다.

```python
logfile = open("log.txt", mode="w", encoding="utf-8")
print(1 + 2 + 3 + 4 + 5, file=logfile)
logfile.close()
```

`write()`와 달리 `print()`는 기본적으로 마지막에 줄 바꿈을 붙이며 숫자도 바로 출력할 수 있다.

추후에는 파일을 자동으로 닫는 `with` 문법으로 확장할 수 있다. 현재 실습은 열기·작업·닫기의 기본 흐름을 익히는 단계다.

## 8. DAY03 — 기존 개념 확장 (2026-11-19)

DAY01의 변수·기본 자료형과 DAY02의 객체 참조·형 변환을 바탕으로, 자료형이 클래스라는 점과 변환 결과를 변수에 연결하는 과정을 확장해서 배웠다.

### 8.1 값과 자료형 함께 확인

실습: [ex_datatype_01.py](../DAY03/ex_datatype_01.py)

```python
msg = "Hello Python"
value = 100.4
age = 100
isok = True

print(f"{msg} 타입 => {type(msg)}")
print(f"{value} 타입 => {type(value)}")
print(f"{age} 타입 => {type(age)}")
print(f"{isok} 타입 => {type(isok)}")
```

각각 str, float, int, bool 클래스의 객체다. `isok`는 사용자가 정한 변수명이며, 예약된 논리값은 `True`와 `False`다.

### 8.2 형 변환과 재할당

실습: [ex_datatype_02.py](../DAY03/ex_datatype_02.py)

```python
num = 4
float(num)          # 반환값을 저장하지 않음: num은 여전히 정수
fnum = float(num)   # 변환 결과를 다른 변수로 참조
num = float(num)    # 기존 이름을 실수 객체에 다시 연결
```

형 변환에 반드시 새 변수명이 필요한 것은 아니다. 기존 이름에도 재할당할 수 있다. 변환은 원본 변수의 자료형을 직접 바꾸는 작업으로 이해하지 말고, 반환값을 어떻게 사용하는지 구분한다. 변환 함수가 언제나 새 객체를 생성한다는 보장도 없다.

| 함수 | 목적 | 예시 |
|---|---|---|
| int | 정수 변환 | `int("100")` → `100` |
| float | 실수 변환 | `float(4)` → `4.0` |
| str | 문자열 변환 | `str(100)` → `"100"` |
| bool | 참·거짓 변환 | `bool(0)` → `False`, `bool(-1)` → `True` |

문자열 `"False"`와 `"0"`은 비어 있지 않으므로 bool 변환 결과가 True다. 숫자의 진법 표기 접두사는 `0b`(2진수), `0o`(8진수), `0x`(16진수)다.

### 8.3 구조체에서 클래스와 객체로

학생 이름·나이·성별·전공·전화번호를 하나의 자료형으로 묶을 수 있다. C의 구조체는 관련 데이터를 묶고, 클래스는 속성과 메서드를 묶는다. 객체는 클래스를 바탕으로 만든 실제 대상이다.

학생 한 명의 평균 계산은 Student에, 여러 학생의 석차·나이순 정렬·전공 통계는 학생 관리 클래스에 두는 식으로 책임을 나눈다. OOP는 객체지향 프로그래밍(Object-Oriented Programming)의 약자다.

### 8.4 C와 Python의 메모리 관리 비교

기본 자료형은 무조건 스택, 컨테이너는 무조건 힙이라는 규칙은 없다. C 구조체는 멤버 구성이 정해지면 구조체 자체 크기도 정해진다.

| 비교 | C | Python |
|---|---|---|
| 동적 할당 | malloc, calloc 등으로 확보 | 객체 생성 시 실행 환경이 관리 |
| 크기 변경 | realloc 등 | 리스트 등 자료구조가 관리 |
| 해제 | free 호출 | 사용되지 않는 객체를 자동 회수 |

동적 할당은 실행 중 메모리를 확보하는 것이다. CPython은 일반적으로 객체를 힙에서 관리한다. Python의 del은 이름·참조를 제거하며 즉시 메모리 해제를 보장하지 않는다. 리스트는 요소 객체에 대한 참조를 저장하므로 C의 연속된 int 배열과 구조가 다르다.

C int 크기는 구현에 따라 다르며 항상 4바이트라고 단정할 수 없다. Python int도 C int와 달리 크기가 고정된 4바이트 정수가 아니다.

### 8.7 문자열: 인덱싱과 슬라이싱

실습: [ex_str01.py](../DAY03/ex_str01.py)

문자열은 여러 문자로 구성된 시퀀스다. 공백도 한 문자로 센다.

```text
문자:       g  o  o  d     l  u  c  k
양수 인덱스: 0  1  2  3  4  5  6  7  8
음수 인덱스:-9 -8 -7 -6 -5 -4 -3 -2 -1
```

```python
msg = "good luck"
print(msg[0])     # g
print(msg[-1])    # k
print(msg[-9])    # g
print(msg[0:3])   # goo
print(msg[0:4])   # good
print(msg[:4])    # good: 시작 생략
print(msg[5:])    # luck: 끝 생략
```

인덱싱은 문자 하나, 슬라이싱은 지정 범위를 가져온다. 양의 기본 진행 방향에서 `[시작:끝]`은 시작 이상·끝 미만이다. 슬라이싱 문법은 `[시작:끝:간격]`으로 확장할 수 있고, 음수 간격에서는 진행 방향이 반대가 된다.

- 첫 문자 인덱스는 1이 아니라 0이다.
- `'good'`를 가져오려면 `[0:3]`이 아니라 `[0:4]`를 쓴다.
- 범위 밖 단일 인덱스는 IndexError가 발생하지만, 슬라이스 경계는 문자열 길이에 맞게 조정된다.
- 문자열은 불변 객체다. `msg[0] = "G"`로 직접 변경할 수 없으며, 새 문자열을 조합해 재할당한다.
- `.upper()` 같은 문자열 메서드도 결과를 반환하므로 원래 이름에 반영하려면 재할당한다.

## 9. DAY04 — 문자열 선택과 길이 (2026-11-20)

DAY03에서 익힌 인덱싱·슬라이싱을 확장해 간격과 방향을 지정하고, 문자열 길이를 확인했다.

### 9.1 양수·음수 인덱스

```python
msg = "Merry Christmas! Happy New Year 2027! "
#                1         2         3
#      01234567890123456789012345678901234567
# 음수 인덱스의 일의 자리:
#      87654321098765432109876543210987654321
```

끝 공백을 포함해 38글자다. 양수는 0~37, 음수는 -38~-1이다. 음수 인덱스의 일의 자리 0은 -30·-20·-10에 해당하며, 마지막 문자가 -0이라는 뜻은 아니다.

| 문자 또는 부분 | 위치·코드 | 결과 |
|---|---|---|
| 첫 문자 | `msg[0]`, `msg[-38]` | M |
| 마지막 공백 | `msg[37]`, `msg[-1]` | 공백 한 문자 |
| 마지막 느낌표 | `msg[36]`, `msg[-2]` | ! |
| Christmas | `msg[6:15]` | 인덱스 6~14 |
| 2027! | `msg[32:37]` | 인덱스 32~36 |
| Merry | `msg[:5]` | 인덱스 0~4 |

### 9.2 생략과 끝 인덱스 주의

```python
print(msg[:])       # 전체 38글자
print(msg[0:37])    # 0~36, 마지막 공백은 제외
print(msg[32:])     # '2027! ' — 끝 공백 포함
print(msg[32:37])   # '2027!' — 끝 공백 제외
```

현재 실습의 `msg[0:37]`과 `msg[:]`는 끝 공백 때문에 결과가 정확히 같지는 않다. 눈에 보이지 않는 공백은 `repr(msg)`나 `len(msg)`로 확인한다. `msg[6:15]`의 범위를 적을 때는 6~14 또는 6 이상·15 미만이라고 표현한다.

### 9.3 간격과 방향: [시작:끝:간격]

```python
sample = "abcdef"
print(sample[::2])   # ace: 인덱스 0, 2, 4
print(sample[1::2])  # bdf: 인덱스 1, 3, 5
print(sample[::-1])  # fedcba: 역순
```

- 기본 간격은 1이다. 2는 공백 두 개를 삽입하는 뜻이 아니라 인덱스를 2씩 이동하는 뜻이다.
- `[::2]`는 0부터 시작하므로 **짝수 인덱스**를 선택한다. 사람 기준으로는 첫 번째·세 번째·다섯 번째 문자다.
- 음수 간격은 오른쪽에서 왼쪽으로 진행한다. `[::-1]`은 전체 문자열을 뒤집는다.
- 간격은 0일 수 없다. `[::0]`은 ValueError가 발생한다.
- 대괄호 내부의 공백은 의미에 영향을 주지 않아 `[ : :-1]`과 `[::-1]`은 같다.

### 9.4 규칙적인 위치에서 숫자 선택

```python
data = "abc1abc2abc3abc4abc5"
print(data[3::4])  # 12345
```

숫자가 인덱스 3, 7, 11, 15, 19에 있으므로 3부터 4칸씩 이동한다. 이 코드는 숫자 여부를 판별하는 기능이 아니라, 이 문자열의 규칙에 맞는 위치를 선택하는 코드다.

### 9.5 len(): 원소 개수

```python
msg = "Merry Christmas! Happy New Year 2027!"
print(len(msg))       # 37: 이번 문자열은 끝 공백 없음
print(len(msg + " ")) # 38: 끝 공백 하나 추가
print(len("123"))     # 3
# len(123)            # TypeError: 정수는 길이를 제공하지 않음
```

문자열에서 공백과 느낌표도 길이에 포함된다. 이 예제의 문자 수와 파일 저장에 필요한 바이트 수는 별개다. len은 str뿐 아니라 리스트 등 길이를 제공하는 객체에도 사용할 수 있지만 int·float·bool에는 사용할 수 없다.

### 9.6 f-string 안쪽 따옴표

```python
print(f"'123'의 원소 개수 => {len('123')}개")
# '123'의 원소 개수 => 3개
```

PY311(Python 3.11)에서는 f-string 바깥과 표현식 안쪽에 같은 따옴표를 사용하면 문법 오류가 날 수 있다. 위처럼 바깥은 큰따옴표, 안쪽은 작은따옴표로 구분하면 된다. Python 3.12 이상은 이와 같은 따옴표 재사용을 허용한다. 현재 실습 파일은 구분한 형태로 작성되어 있다.
